
# Industrial Machine Health Monitoring and Predictive Maintenance Using IoT and AI

## Description
An IoT-based system that monitors industrial machine conditions in real time using ESP32 sensors, MQTT communication, and a web dashboard.

## Purpose
To detect abnormal machine conditions early, generate alerts, and provide a foundation for AI-based predictive maintenance.

## Working
1. **ESP32:** Collects temperature, humidity, gas, and vibration readings.
2. **MQTT (Mosquitto):** Transfers sensor data to the backend.
3. **FastAPI:** Processes readings and evaluates alert thresholds.
4. **SQLite:** Stores telemetry and alerts.
5. **React.js:** Displays sensor readings and machine status on the dashboard.
6. **AI/ML (Future Scope):** Enables anomaly detection and predictive maintenance.

## Technologies Used
- ESP32 and IoT Sensors
